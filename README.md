## Featured Work

### SmartServe — Food Surplus & Discount Marketplace

SmartServe is a multi-role marketplace connecting customers with discounted food offers while supporting end-to-end vendor, delivery, and administrative workflows. It was developed as my final-year Computer Science project and received a grade of **80/100** under the supervision of **Dr. Rodayna Hmede**.

**What I built:** authentication and role-based access for guests, customers, vendors, delivery staff, and administrators; deals, carts, checkout, orders, notifications, vendor management, delivery workflows, mobile experiences, and a role-aware AI assistant.

**Stack:** Laravel 12 · PHP · MySQL · REST APIs · React · Vite · Tailwind CSS · Ant Design · React Native · Expo · Expo Router · n8n · LLM API integration · Docker · VPS
